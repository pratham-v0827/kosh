# 0013. shadcn/ui Charts (Recharts) for v1

- Status: Accepted
- Date: 2026-11-09
- Details: [docs/PLAN.md](../PLAN.md)

## Context

Daily financial series need themeable, accessible charts that match the design system.

## Decision

Use shadcn/ui chart components (Recharts) everywhere in v1.

## Consequences

One library, shared tokens, SVG accessibility.

## Would change if

Candlesticks or very dense intraday data → TradingView Lightweight Charts.
