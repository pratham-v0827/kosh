# 0016. Licence: AGPL-3.0-only

- Status: Accepted
- Date: 2026-11-09
- Details: [docs/PLAN.md](../PLAN.md)

## Context

Kosh is self-hostable software that others may run as a service.

## Decision

License the repository under AGPL-3.0-only.

## Consequences

Hosted forks must share changes. Self-hosting stays free.

## Would change if

Wanting maximum reuse in closed products → MIT or Apache-2.0.
