# Phase 2 — bug audit (2026-11-09)

Scope: maths (FIFO, P&L, XIRR, day change), FX, time zones, refresh concurrency, input validation
(bounds, decimals), auth/session handling, UI states and number formatting.

Method: baseline run (install, format, lint, typecheck, unit tests, rules tests, build), code
review, then for every confirmed bug: a failing test first, the fix, and the test passing.
Live checks ran against the local emulators and dev server only (`pnpm smoke`, browser pane).

Severity: **High** = wrong money figures or data loss for normal use · **Medium** = wrong figure
or broken flow in a common case · **Low** = edge case, cosmetic, or wasted work.

## Also verified (no bug)

- XIRR known values: partial sell (0.2787085013, independent bisection), same-day plus zero
  flows (15%), single transaction, zero duration, no sign change — `audit-phase2.test.ts`.
- US holdings: buy stored in USD with the trade-date ECB rate; value = USD price × latest FX.
- Ticker with a dot (`BRK.B`) as a Firestore map key: stored, priced and valued (smoke).
- Session expiry after an emulator reset: the app returns to sign-in, as intended.
- Exchange picker (NSE/BSE) appears only for Indian stocks; the date picker's max is today in IST.
- Every API route is request-time (ƒ) in the build output; nothing is prerendered.

## Not fixed here (tracked for later phases)

- The packages (`core`, `contracts`, `prices`) have no lint task; only `apps/web` is linted. To be
  added with CI in Phase 4.
- Two concurrent refreshes can both call providers before the transaction rejects one (one wasted
  set of requests; budgets still hold). Acceptable; revisit if limits are reached in practice.
